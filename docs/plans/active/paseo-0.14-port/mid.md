## Protocol, schema and config changes that need compatibility handling

JAgentDesk's protocol already differs from upstream: 69 of 123 `packages/protocol/src` files differ from rebranded v0.10.2. JAgentDesk also adds `server_info` host capabilities (spec 24.2) and tailnet pairing. Every item below must stay **additive and optional**, so that older JAgentDesk apps (mobile builds lag behind) keep working.
