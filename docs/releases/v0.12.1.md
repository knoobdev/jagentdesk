# JAgentDesk v0.12.1

Fixes the Devices screen, which opened to "Something went wrong — Error: Invariant failed" in v0.12.0.

## Fixes

- **Devices, Clusters, Data and Workbench no longer crash when they show their agent chat.** These screens embed an agent chat outside a
  workspace. The tracker pills above its composer (background work, subagents) open their lists in the workspace's sheet, and
  outside a workspace there is no sheet host, so a required-context check failed and took the whole screen down. Embedded chats
  now get one shared set-up from the plugin host API, and without a sheet host the pills simply don't open a sheet.
- A browser test renders the agent chat outside a workspace exactly as these screens do; it fails with the same error on v0.12.0.

## Breaking changes / action needed

- None. Install v0.12.1 on desktop and phone if you use Devices, Clusters, Data or Workbench.
