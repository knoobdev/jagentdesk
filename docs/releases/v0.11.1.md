# JAgentDesk v0.11.1

Phones connect again after pairing, long agents stop redoing old work, agents never open your real browser, bot permission
cards answer instead of spinning, and closing an agent no longer spawns a pile of empty tabs. This release also brings in
Paseo 0.17.4 and 0.17.5: OpenCode agents with their own MCP servers on a shared OpenCode server, a redesigned host picker,
multi-select archiving in the sidebar, the new agent profiles settings, and plugins that can run agents and worktree commands
behind a sandbox launcher.

## Highlights

### Phones connect after pairing

- Since v0.10.0 the iPhone and Android apps could pair but never finish the first connection ("challenge timed out; refusing
  unsigned hello"). The phone build validates daemon messages with a smaller validator than the desktop, and that validator
  lacked two pieces the message reader needs, so every message from the host was rejected. It now has them, and a test runs
  the phone's exact validation path so this cannot drift again.
- **Settings → Diagnostics → Connection log** (phone and desktop) shows each step of the connection with **Copy logs**, and
  handshake problems now fail with a named reason instead of timing out silently.

### Long agents keep working on what you asked

- The per-turn reminder no longer uses your oldest message as the agent's goal. A goal only appears when the agent recorded
  one in its ledger; with nothing recorded there is no reminder line at all.
- Re-grounding after compaction, provider handoffs, rollovers and child handoffs list your messages newest first, with times,
  and say that older requests may already be done.
- Every agent is told its own JAgentDesk id, and reads other agents (including archived ones and other providers) with
  JAgentDesk's agent tool instead of searching provider folders.

### Your browser stays yours

- Agents' `open`, `xdg-open` and `$BROWSER` go through JAgentDesk: web pages, HTML and PDF files open as tabs in the app.
- Dev servers that open a browser by themselves (Vite `server.open`, Create React App, webpack-dev-server) now open their page
  in the app too — on macOS Vite used to drive Chrome directly.
- With no JAgentDesk browser connected the command fails with a clear message; it never falls back to your system browser.
  Opening apps and other files (`open -a Preview`, spreadsheets) works as before.

### Bots: permission cards that answer

- Cards for requests OpenCode had already forgotten (after a restart, or answered while disconnected) are removed instead of
  spinning forever; expired requests disappear with "This request is no longer pending".
- A failed answer stops the spinner and shows the error on the card, for every provider.
- Bot permission cards sit under **Needs you** at the top of the Items tab instead of covering every tab, and show the request
  (for OpenCode, the directories it asks for).
- Closing a bot's tab only hides it; it no longer archives the bot.

### OpenCode with its own MCP servers (Paseo #10752, #4009)

- OpenCode agents receive JAgentDesk tools through JAgentDesk's OpenCode plugin. An agent's own MCP servers and environment
  work on a shared OpenCode server and are visible only to that agent and its subagents.
- JAgentDesk picks the path per OpenCode server: OpenCode 2.0.29 and newer use the per-session path; older servers keep the
  previous `mcp.add` path, so no session fails because of the OpenCode version.
- If you run your own `opencode serve --service`, JAgentDesk installs its plugin there and runs agents on that service; your own
  OpenCode sessions do not see JAgentDesk's tools.

### From Paseo 0.17.4 and 0.17.5

- Host picker with auto-detected icons, connection type and latency.
- Select several workspaces in the sidebar (Cmd/Ctrl-click, Shift ranges) and archive them together.
- Agent profiles: a new settings page and inspector drawer, profiles in model search and the Command Center, drag to reorder on
  phones.
- Add a project from one sheet with Existing, Clone and New folder tabs.
- Import Session keeps slow results and shows provider errors; empty ACP sessions are hidden.
- Parents keep getting notified when a child agent ends a turn with background work still running.
- Plugins can manage worktrees and run agents, terminals and worktree commands behind a sandbox launcher; a reloaded plugin's
  tools keep working for a busy agent.
- Claude MCP servers are passed over stdin (no tokens in process arguments); Codex keeps your configured developer
  instructions; OMP 19.1+ forms show as question cards; leftover provider processes stop when a catalogue refresh times out.
- Push and Pull for branches that were never pushed or whose remote is not `origin`; Git watchers stay responsive on large
  folders and rescan only affected checkouts.
- Faster overlays and long sessions; long desktop turns stay virtualized; archived chats free their memory.

## Fixes

- **Closing an agent tab opened several blank "New Agent" tabs** (seen in bot workspaces): opening agents from the Workspace
  Agents column stacked copies of the workspace, and each copy opened a draft. Now one draft at most, only when the workspace is
  really empty.
- **Failover / Child agents on other providers → Add provider** asks for a provider, then one of its models (searchable),
  instead of listing every model of every provider.
- **Sidebar Usage summary** shows again when the host marks a source off by default, and skips pins a provider stopped
  reporting.
- **The desktop talks to its own daemon locally**: after a daemon restart it could stay on the relay route and show
  "Connection · Relay"; the local route now always wins.
- **Codex** no longer asks a second time before every JAgentDesk tool call.
- The "Turn on … for this host?" card no longer says "Browser tools tools".

## Breaking changes / action needed

- No protocol break: v0.11.0 and v0.11.1 apps and daemons work together.
- **iPhone and Android: install the v0.11.1 app.** The connection fix is in the app; a phone you already paired connects without
  pairing again.
- OpenCode tool delivery changed (see above); nothing to configure.

## Upgrade notes

- Agents created before this release may carry a ledger without a goal; the reminder line stays off until the agent records one.
- The first OpenCode agent after updating installs JAgentDesk's OpenCode plugin into the OpenCode server it uses.

## Known limits

- Not ported from Paseo 0.17.5: enabling the operating system's Tailscale from settings (JAgentDesk embeds its own Tailscale)
  and the desktop auto-update pacing (JAgentDesk has no auto-updater yet).
- ACP providers (Copilot, Cursor, Kimi, Kiro) ignore system instructions, so the agent-id line does not reach them.
- On Windows, `start` and `Start-Process` cannot be redirected; there agents are only instructed to use the in-app browser.
- Several checks ran on the web build or a simulated browser host rather than the Electron app or a real phone; the phone
  connection fix is confirmed on a real device after this release.
