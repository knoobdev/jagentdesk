# JAgentDesk v0.10.1

A fix release for v0.10.0. The iOS app opens again, plugins load in the desktop app, and a Docker leak that
slowed the whole computer is gone. Connecting a new device no longer asks you to pick "Tailscale or Local":
the desktop connects to its own daemon by itself, and a phone pairs by scanning a QR code or pasting a link,
through the encrypted relay, with Tailscale as an option. Bots can be created without an identity, the
model picker is searchable, and the Bots screen now explains how bots work.

## Highlights

### The iOS app opens again

v0.10.0 crashed on launch on iPhone with `TypeError: Cannot read property 'includes' of undefined`. The
terminal emulator library (`@xterm/headless`) reads `navigator.userAgent` while it loads, and React Native
has no user agent. The polyfill that sets one now runs before any other module loads (from Paseo #6734).

### Plugins work in the packaged desktop app

In the v0.10.0 desktop app many plugins showed "Unavailable" with `Cannot find module 'typescript'`.
Two causes, both fixed:

- `typescript` was a development-only dependency, so the installer left it out. It is now shipped.
- Built-in plugins were compiled from inside `app.asar`, which the compiler (esbuild) cannot read. They are
  now compiled from `app.asar.unpacked`.

### No more `docker events` pile-up

With the Docker plugin on, the v0.10.0 daemon started a new `docker events` watcher about every 50 seconds and
never stopped the old ones. After a few hours the computer had hundreds of `docker` processes and slowed
down. Watchers that are cancelled while the first container list loads no longer start, and watchers that
exit are forgotten. The same fix applies to Docker over SSH.

### Simpler first run: QR code or link, Tailscale optional

- **Desktop:** the "Connect type: Tailscale | Local" screen is gone. The app connects to the daemon it
  started (shown as **Local**) and opens the main screen. You can still sign in to Tailscale in
  Settings → host.
- **Phone:** after the welcome screen, **Connect your workstation** offers **Scan QR code** (encrypted relay
  connection), **Paste pairing link** (encrypted relay connection) and **Sign in to Tailscale** (direct tailnet
  connection). On the workstation, open JAgentDesk → **Pair a device**.
- A pairing link carries every route the daemon has (relay and/or Tailscale). A link that only has a Tailscale
  route opens the Tailscale sign-in first, then comes back to the pairing screen.
- **Pair a device** works while the daemon is not on Tailscale, as long as the relay is on (the default).
  If both the relay and Tailscale are off, the link only works on the same computer and the panel says so.

### Bots: easier to create, explained in the app

- **Identity is optional.** Leave it empty and the bot gets a default identity; `SOUL.md` is never empty. The
  slug is filled in from the name until you edit it.
- **Clear errors.** Each field shows its own message under it, and **Create bot** says why it is disabled.
  The old one-line error about slugs and look-around intervals is gone.
- **Searchable pickers.** Type in the **Provider** and **Model** pickers to filter, by name or id.
- **In-app help.** With no bots yet, a "Your AI teammate" card explains the three steps. Each form field has a
  one-line hint. Chat shows "How to ask" before the first message, and the Items, Soul & Memory and Schedules
  tabs explain themselves when empty. The **?** button on a bot opens **How bots work**.

### Cleaner pages and sidebar

- **Full width everywhere.** Every page — Home, History, Skills, Bots, Settings, Usage and every plugin screen — uses
  the whole content area with the same 32 px margin on both sides. Titles, tabs, filters, search boxes and lists
  start on one left edge; no page stops short or runs to the edge any more.
- **A title and one description line on every page.** Home now reads "Your latest agents on every host. Open one to
  pick it up, or start a new one."; Usage, Settings and plugin pages got theirs too.
- **Smaller text in the sidebar, buttons and menus** (14 px instead of 16 px), with 8 px between icon and label.
- **Tools are easy to find.** The Tools group sits right under the main menu, open by default, with a count and
  the same look as Home, History and the rest. A Tools group that v0.10.0 collapsed by itself opens again once.

### Tighter lists

Rows in History, Docker (containers, images, volumes, compose groups), Kubernetes, Databases, SSH
servers, Schedules and bot items are 44 px (56 px for two-line rows), down from 72 px. Day and group labels
sit right above their rows.

## Breaking changes / action needed

- **iPhone users on v0.10.0:** the v0.10.0 IPA crashes on launch. Install the v0.10.1 IPA.
- **Desktop v0.10.0 with Docker on:** if the computer is slow, quit and reopen the app once after updating;
  the update itself stops the leak, but watchers started by the old daemon end when it exits.
- No protocol break. Apps and daemons of v0.10.0 and v0.10.1 work together. A v0.10.1 app talking to a
  v0.10.0 daemon sends the bot name as its identity when you leave Identity empty.

## Upgrade notes

- The stored "Connect type" choice from v0.10.0 is migrated on first launch: "Tailscale" keeps your tailnet
  sign-in, "Local" means no tailnet. Nothing to do.
- A v0.10.0 desktop that only saved its own daemon's Tailscale route gets the Local route added, so it
  connects even when Tailscale is down.
- Pairing a phone over the relay no longer turns off an existing Tailscale sign-in on that device.
- The iOS IPA is now built with Xcode 26 (Expo 57 needs Swift 6.2).

## Fixes

- **iOS:** launch crash `Cannot read property 'includes' of undefined` (navigator polyfill installed before
  any module loads; Paseo #6734).
- **Desktop:** plugins "Unavailable — Cannot find module 'typescript'" (`typescript` shipped as a runtime
  dependency; built-in plugins compiled from `app.asar.unpacked`).
- **Docker:** `docker events` watchers leaked when a subscription was cancelled during the first list, or
  requested twice; local and SSH.
- **Bots:** a bot could not be created with an empty Identity; the form showed one generic error for every
  field.
- **Desktop:** the connection to the desktop's own daemon is labelled **Local**, not **Direct**, and its
  hello is device-signed on the reachability probe as well as the session.
- **Releases:** a new release is no longer marked Latest by GitHub before its files are checked.
- **Desktop (macOS):** double-clicking the title row of Home, History, Docker and other pages now zooms the
  window (it is a window drag region), and the traffic lights line up with the logo in the Gumloop sidebar.

## All changes

### Onboarding and connections

- "Connect type" chooser and the forced Tailscale sign-in on desktop removed (ADR-0056).
- Desktop connects to the daemon it started and remembers which daemons it started.
- **Connect your workstation** screen on phones (Scan QR code, Paste pairing link, Sign in to Tailscale); the
  same three options in Settings → add host.
- Startup failure screen offers **Paste pairing link** next to Retry.
- A Tailscale-only pairing link sends you to Tailscale sign-in and back.
- **Pair a device** warns when the link only reaches this computer.

### Bots

- Identity optional with a default; slug from name; per-field errors; Create bot explains what is missing.
- Searchable Provider and Model pickers (New bot and bot Settings).
- In-app help: "Your AI teammate" card, field hints, How to ask, empty-tab hints, **How bots work** sheet.

### Desktop UI

- Full-width pages with 32 px margins; one-line description on every page; 14 px sidebar, buttons and menus.
- Tools group open by default under the main menu.
- Page title rows drag and zoom the window; traffic lights centred on the brand row.
- 44 px rows for History, Docker, Kubernetes, Databases, SSH servers, Schedules and bot items.

### Mobile

- Launch crash fixed (see Fixes).
- Onboarding: Scan QR code first, Tailscale optional.

### Plugins and daemon

- `typescript` runtime dependency; built-in plugins compiled from `app.asar.unpacked`.
- Docker events watcher leak fixed (local and SSH).

### Build and release
