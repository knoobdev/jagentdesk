# JAgentDesk v0.10.0

A new app with the Gumloop theme: one sidebar on desktop, a drawer on phones.
Reach your daemon through an encrypted relay as well as Tailscale, and switch built-in features such as Docker, Kubernetes and Databases off per host.
Bots replace Team mode, daemons can connect to each other, and Usage shows the plan limits of every agent account.
Underneath: everything from Paseo 0.11 to 0.17.3, Expo 57, a 10,000-row terminal and Paseo's agent lifecycle.

## Highlights

### A new app: Gumloop theme, one sidebar, a drawer on phones

The ClickUp theme, its icon rail and top bar are gone. Desktop now has one sidebar: your host, **New
agent**, Home, History, Schedules, Skills, Bots, Market, Usage and Insights, a **Tools** group (Docker,
Devices, Workbench, Data, Servers, Clusters, Argo CD, Jira, Forge), your projects, and a footer with your
plan usage, the connection card and Pair device / Settings / Notifications / More. Opening a workspace,
Settings or a tool drills the sidebar into that area with a back arrow. Collapse it with ⌘\ / Ctrl+\.
On phones there is no tab bar any more: the same sidebar opens as a drawer, panes open as sheets,
Settings are grouped tiles, and Scripts, files and subagents have their own pages. The composer has a
gradient frame, a fullscreen mode and shared toolbar controls. Both light and dark Gumloop themes are
included and Gumloop is the new default; if you used ClickUp, ClickUp Dark or the automatic theme, you
are switched to Gumloop. The other colour themes (Light, Dark, Zinc, Midnight, Claude, Ghostty, Pure
black) are still available in **Settings → Appearance** and keep the classic layout.

### Encrypted relay alongside Tailscale

A daemon can now be reached through an end-to-end encrypted relay (a Cloudflare Worker) in addition to the
embedded Tailscale listener. Both paths share the same host and pairing: a pairing link or QR code carries
the relay route when it is enabled, the app fails over between Tailscale and the relay, and **Settings →
host → Connections** shows which path is active and lets you enable the relay per connection. The relay
only forwards encrypted frames and never holds daemon or device keys. `jagentdesk relay reset` clears the
relay ownership pin when you move a daemon to a new machine.

### Built-in plugins with per-host switches

Seventeen features now ship as built-in plugins: Docker, Kubernetes, Databases, Argo CD, SSH servers,
Remote tasks, Custom API providers, Jira, Forge Hub, Devices & simulators, Workbench, Skills, Spec mode,
Autonomous run, Insights, Session sharing and Agentic browser — alongside Bots, Worktree include, bundled
agent providers and Usage sources. **Settings → host → Plugins** lists them with a switch each. Turning a
plugin off hides its screens, sidebar entries and agent tools on that host and stops its background
services; your data stays. Autonomous run, Session sharing and Agentic browser are installed but off by
default; everything else is on. Remote tasks needs SSH servers, Argo CD needs Kubernetes.

### Bots replace Team mode, with Slack

Team mode (task board, virtual office, group chat) and the agent forum are removed. In their place,
**Bots** are long-lived assistants built on the Supervisor → Lead → Peer orchestration that stays in
JAgentDesk. A bot has its own identity, chat, work items (Planned, Working, Waiting, Needs you, Done),
memory, schedules and settings. It hands real work to worker agents in their own worktrees, and the
BA / Tester / Pentester cross-review checks the result before the bot reports back. When a bot needs you,
the item shows the question with quick answers. Bots can also talk in Slack: the Slack app sends events
through the relay Worker to your daemon, and the bot replies in the thread.

### Connected hosts

A daemon can now pair with another daemon (SAS codes on both sides, no password or SSH to the other
daemon). Once connected, agents can start and message agents on the other host, files move between hosts,
and a parent agent learns when a remote child finishes — even if one side restarts. Manage connections
with `jagentdesk host ls`, `host add` and `host update`.

### Usage and Insights

Usage follows Paseo's usage plugin. Each agent account (Claude, Codex, GitHub Copilot, Cursor, OpenCode
Go, OpenRouter, Kimi, Grok, MiniMax, Z.ai) has a card with its limits, when each limit resets and a
forecast of when you will run out. Open it from the sidebar footer or **Usage**; reorder or hide cards,
choose which host to read, and turn sources on or off. An agent's own plan usage also shows in its
context-window details. `jagentdesk usage ls` and `usage inspect` print the same reports. **Insights**
stays next to it as a built-in plugin, now with per-turn metrics.

### Paseo 0.11 → 0.17.3

JAgentDesk now includes the upstream work from Paseo 0.11 through 0.17.3. The parts you will notice:

- **Chat:** completed turns fold behind a "Worked for …" summary, tool calls group under one reply,
  long chats scroll smoothly on a rebuilt native list, reading position holds when history loads.
- **Markdown:** one enriched renderer for chat and files, selectable and copyable code with indentation
  kept, local images, Mermaid fixes, links that open in Files.
- **Files:** a file panel with **Preview** and a CodeMirror **Source** view that you can edit and save;
  word- and line-selectable diffs.
- **Composer:** model, effort and permission pills, skills from the slash menu, fullscreen editing,
  long-press Send to queue or send now, ↑/↓ to recall sent messages, a configurable send shortcut.
- **Command Center:** tabs, recent and archived workspaces, rewind the latest turn, draft agent settings.
- **Workspaces:** start in an existing worktree or check out any branch or pull request, archive with
  undo, change a worktree's base from Changes, background workspaces.
- **Providers:** OMP is a first-class provider; Antigravity, Muse Code, Hoplite, fx and goose ship as
  bundled provider plugins; Codex Fast and Ultrafast speeds; provider versions and updates in Settings;
  model catalogs refresh every 30 minutes; Claude Haiku 5.5, Fable 5.2 and Mythos 5.1 / 5.2.
- **First-run setup** walks new users through JAgentDesk.

### Agent lifecycle and messaging

JAgentDesk now follows Paseo's agent lifecycle. An agent that has been idle for an hour releases its
process but keeps its conversation; your next message resumes it (**Settings → host → Agents → Release
idle agents**). Restored agents get a fresh idle window, and Claude agents with pending crons or loop
wake-ups are kept. Agent-to-agent messages now **queue** until the recipient's current turn ends, in
order; `steer` and `interrupt` are still available. A parent waiting on children is woken after a daemon
restart, and a child's finish is recorded once even across restarts. Background work and heartbeats are
listed and can be stopped.

### Terminal: 10,000 rows that survive restarts

The daemon keeps the last 10,000 rows of every terminal and replays them with colours, cursor and mouse
mode when you reopen it, on any device. Terminals keep running through daemon restarts, crashes and
updates. iOS and Android use a native terminal renderer with selection handles, and files can be pasted
or dropped into a terminal.

### Tailscale 1.106.1

The embedded Tailscale in the daemon and in the mobile app moves from 1.80.0 to 1.106.1, and the version
string is reported correctly again.

### Expo 57 and React Native 0.86

The mobile and web app now run on Expo 57 and React Native 0.86, with scene support on iOS, foldable and
external-display handling on Android, and keyboard shortcuts on tablets with a hardware keyboard.

## Breaking changes / action needed

- **Update the app before pairing a new device.** Pairing now uses SAS: both screens show the same
  six-digit code and you approve on both. Apps older than 0.10.0 cannot pair a **new** device with a
  0.10.0 daemon. Devices that are already paired keep working.
- **Team mode is removed; use Bots.** The task board, virtual office, group chat and agent forum are
  gone. Old Team mode data stays on disk but is no longer shown.
- **Activity graph and Figma are removed.** Their screens, agent tools and settings are gone.
- **The ClickUp theme is removed.** ClickUp and ClickUp Dark switch to Gumloop and Gumloop Dark. The new
  sidebar and drawer come with the Gumloop themes; other colour themes keep the classic layout.
- **Agent-to-agent messages queue by default.** A message to a busy agent now waits for the current turn
  to end instead of steering into it. Ask for `steer` or `interrupt` when you want the old behaviour.
- **Idle agents release their process after one hour.** Their conversation stays and the next message
  resumes them. Turn this off per host in **Settings → host → Agents → Release idle agents**.
- **Tailscale access is checked per device.** The daemon only accepts tailnet peers signed in to the
  same Tailscale account. If one side uses Tailscale tags and the other does not, the connection is
  refused with `wrong_tailnet_account`; tag both or neither.

## Upgrade notes

- **The daemon restarts once on update.** The desktop app replaces its own daemon after it relaunches.
  Terminals keep running through the restart; agents that were working are restored, and idle ones
  resume on your next message.
- **Paired devices stay paired.** Only pairing a new device needs a 0.10.0 app (see above).
- **Theme:** ClickUp → Gumloop, ClickUp Dark → Gumloop Dark and the automatic theme → Gumloop happen on
  first launch. A colour theme you picked yourself is kept.
- **Removed plugin settings are ignored.** Saved `builtinPlugins.figma` and
  `builtinPlugins.activity-graph` keys in the daemon config do nothing and can stay.
- **Figma credentials are deleted.** On its first start the daemon deletes the stored Figma credentials
  and the Figma render cache once and logs one line. Your saved Figma connection and file lists stay on
  disk.
- **Team mode data stays on disk.** Nothing under the old Team mode or forum folders is deleted.
- **Built-in plugins start with their defaults.** Everything is on except Autonomous run, Session
  sharing and Agentic browser. Your Docker, Kubernetes, Databases, SSH, Jira and other data is read from
  the same place as before.
- **The relay is on by default.** Turn it off per connection in **Settings → host → Connections**, or
  for the daemon with `daemon.relay.enabled: false` in `config.json` or `JAGENTDESK_RELAY_ENABLED=0`.
