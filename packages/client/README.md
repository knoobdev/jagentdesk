# @jagentdesk/client

JAgentDesk's JavaScript/TypeScript client package.

## Stability

This package is public so JAgentDesk's published packages can depend on it cleanly.
It is not a stable public SDK yet.

APIs, exports, runtime behavior, and types may change or disappear in any
release without advance notice. Use it outside JAgentDesk at your own risk until the
package is explicitly documented as stable.
